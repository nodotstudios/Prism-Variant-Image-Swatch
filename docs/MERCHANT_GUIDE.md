# Merchant User Guide — Prism Variant Image & Swatch

Welcome to **Prism Variant Image & Swatch**! This app allows you to display specific images, videos, swatches, and 3D models when customers choose visual variant options (like *Black + Leather*).

## Quick Start Guide

### 1. Mapping Media for a Single Product
1. Open the app from your Shopify Admin.
2. Go to **Products Catalog** and click **Edit Media Map** next to any product.
3. Check the options that control media (e.g. `Color`, `Style`, `Material`).
4. Click on a visual combination button (e.g., `Black / Leather`).
5. Check the images, videos, or 3D models to assign to that combination.
6. Click **Save Mapping**.

### 2. Using Shared Media
If an image or video should show up for *all* variants (for example, a size chart video or brand hero image), check **Shared (All)** on that media item.

### 3. Bulk Automated Mapping
For large catalogues (1,000+ products):
1. Go to **Bulk Mapper**.
2. Define filename rules (e.g. filenames containing `black-leather` map to *Black / Leather*).
3. Run the bulk rule engine to update all matching products in seconds.
